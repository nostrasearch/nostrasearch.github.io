## 🚀 About

**Nostra Search** is an experimental decentralized search engine built on top of the **Nostr** ecosystem.

Instead of relying on a centralized index, users authenticated with Nostr can submit and curate websites, creating a community-driven search index.

### Features

* 🔎 Fast search experience
* 🌐 Decentralized indexing
* 🔐 Nostr authentication
* 👥 Community-powered search results
* ⚡ Built with React + Vite
* 📱 Responsive interface
* 🚀 Automatic deployment with GitHub Pages

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/nostrasearch/nostrasearch.github.io.git

cd nostrasearch.github.io
```

Install dependencies:

```bash
npm install
```

---

## 💻 Development

Start the development server:

```bash
npm run dev
```

---

## 🏗 Build

Generate a production build:

```bash
npm run build
```

The compiled files will be available inside:

```text
dist/
```

Preview the production build locally:

```bash
npm run preview
```

---

## 🚀 Deployment

This project is automatically deployed through **GitHub Actions**.

Every push to the **main** branch triggers:

1. Install dependencies
2. Build the application
3. Deploy to GitHub Pages

The website is available at:

**https://nostrasearch.github.io**
